YEAR 7 / SENIOR SCHOOL

Rugby School Dubai — App Directory & Links

A central guide for parents and students to track all required platforms, web portals, mobile apps, and access methods for 2026/27.

About This Directory:

This page details every app required for Year 7 at Rugby School Dubai. Direct links for both Parent Access and Student Access (Web, iOS, Android) are listed for quick reference.

  • Parent Access: Yes indicates a platform where parents can log in, view progress, set preferences, or manage payments.
  • Use the search bar below to filter apps by name, feature (e.g., homework, canteen, photos, fees), or contact.
iSAMS / iParent
Parent Access: Yes
Main school communication platform for viewing timetables, academic reports, attendance, rewards, school calendar, and contact updates.
👨‍👩‍👧 Parent Access & Downloads
🌐 Web Portal: rugbyschool.parents.isams.cloud
📱 iOS App: iParent on App Store
🤖 Android App: iParent on Google Play
🎓 Student Access & Downloads
🌐 Web Portal: rugbyschool.students.isams.cloud
📱 Mobile App: iStudent App (iOS / Android)
Setup Credentials School App Code: RSD1
Registration credentials sent via email by Admissions upon enrollment.
Main Contact Parent Relations Manager: prm@rugbyschooldubai.ae
Admissions Team: admissions@rugbyschooldubai.ae
Sparx Maths
Parent Access: Yes
Online personalized mathematics learning and homework platform used across Year 7, tailored to individual student progress.
👨‍👩‍👧 Parent Access & Downloads
🌐 Parent Portal: Access link is emailed weekly in Sparx summary updates.
📖 Parent Guide: sparxmaths.com/parents
🎓 Student Access & Downloads
🌐 Student Web Login: auth.sparxmaths.uk/student
Setup Credentials Student accounts are created automatically by the school. Parents receive weekly email updates with a direct link to the Sparx Parent Portal.
Main Contact Child's Year 7 Maths Teacher or Form Tutor
SOCS
Parent Access: Yes
Management platform for Co-Curricular Activities (CCAs), preferential activity choices, sports fixtures, and team schedules for Senior School.
👨‍👩‍👧 Parent Access & Downloads
🌐 Parent Web Portal: socscms.com/login/parent
(Search for "Rugby School Dubai". Can be saved as a Web App on iOS/Android home screens.)
🎓 Student Access & Downloads
🌐 Student Web Portal: socscms.com/login/student
Setup Credentials Activate parent account using the email address registered in the school iSAMS database.
Main Contact Senior School (Y7–Y13): lreiners@rugbyschooldubai.ae
